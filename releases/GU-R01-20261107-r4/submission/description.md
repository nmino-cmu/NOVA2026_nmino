## Description

Ghost Users runs a browser task locally, keeps the witnessed clicks, and replays them from a fresh start. The answer is the best verified workflow under the declared budget, not a success screen.

Ghost Users is a self-hosted investigation tool. A developer sets the page, the goal, the allowed actions, and the budget. A local Chromium session performs the clicks. An OpenRouter model may choose only from the controls the page is already showing. The product then resets the controlled Orbit Supply shop and replays that exact sequence. The checkout goal reads the shop's authoritative cart. A page that says checkout is ready still fails when the cart is empty.

The technical piece is the split between the witnessed history and the check. The live run run_c6252c9a4a6e4ba2 on build orbit-buggy-v1 verified a 6-interaction route and stopped with completed_target. Its first click was Express Nova Mug. The separate Express regression run_f14d218e9d8c4dff failed the cart check after one click. The ordinary fixture route run_b1a8b04516204ce7 passed in five clicks. Those fixture routes are labeled checks. The model was not given them as a script.

Install from source with the pinned requirements file, start Ghost Users on 127.0.0.1:8787 and Orbit Supply on 127.0.0.1:8788. Recorded playback of run_c6252c9a4a6e4ba2 needs no API key. There is no public deployment URL in this package.

Measured on this machine: the live run used 6 model requests, 4303 tokens, and reported about $0.0176. The Express check reported no model charge. This is one task, one budget, and one witnessed path. It is not a claim that six interactions is the shortest route, and there is no comparative study.
