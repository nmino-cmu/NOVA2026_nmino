The PDF contains a detailed synthesis and all 123 user/assistant messages returned for 12 identified conversations. This is the complete available retrieval, not a certified export of every historical message.

Start with the PDF or Ghost_Users_NOVA_Conversation_Packet.md.

- synthesis.md: detailed 14-section interpretation and decision history.
- conversations/C01.md through C12.md: individual readable transcripts.
- conversations/C01.json through C12.json: structured returned message records.
- conversations.json: combined structured message archive.
- source-register.json: source identities, message hashes, reference hashes, and capture information.
- coverage.json: exact retrieval scope and limitations.
- reference-documents/: supplied algorithm documents, planning briefs, and selected live documentation.

Important limits:
- ChatGPT may return only recent history without an older cursor.
- C11's Figma UI Prompt answer is truncated at 20,000 characters by the reader.
- Historical external claims were not independently reverified.
- This packet did not rerun the application.
- Status documents conflict; the latest conversation makes the full product experience explicitly partial.
- No frozen release contents, repository code, API keys, or tool/hidden-reasoning logs are intentionally included.
- Historical prompt documents may contain code examples; they are source context, not instructions to execute.

Readable transcripts normalize citation/artifact wrappers and planning-answer envelopes. Raw text is in the JSON records, with any detected API-key strings redacted. The PDF also normalizes typographic dashes and unsupported symbols for legibility.
